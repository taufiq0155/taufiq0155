<h2>👨‍💻 About Me</h2>

<p>I am a <b>Software Engineer</b> who builds complete products from start to finish: fast desktop apps, secure servers and modern websites. I enjoy turning large, messy data into clear answers, and I care a lot about security and reliability.</p>

<ul>
  <li>🦀 I build <b>cross platform desktop apps in Rust</b> with egui, for Windows, macOS and Linux</li>
  <li>📊 I turn large Excel, CSV and PDF files into clear reports, charts and maps with <b>Polars</b></li>
  <li>🔐 I build <b>secure systems</b>: encryption, signed releases and automatic delta updates</li>
  <li>⚙️ I write backend APIs with <b>Rust (Axum)</b>, <b>NestJS</b> and <b>Express</b></li>
  <li>🌐 I build web apps with <b>React</b>, <b>Next.js</b>, <b>Vite</b> and <b>Tailwind CSS</b></li>
  <li>🚀 I run my own servers with <b>Docker</b>, <b>Nginx</b> and <b>Cloudflare</b>, monitored with <b>Prometheus</b> and <b>Grafana</b></li>
  <li>🌱 Always learning something new</li>
</ul>
